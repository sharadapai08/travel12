# Travel Planning and Booking Website

## Project Overview
A web-based travel planning and booking application that helps users explore travel options, make bookings, and share reviews.

## Features
- User Registration and Login
- Travel Planning and Booking
- Review Management
- Admin Dashboard
- Booking and User Management

## Technologies Used
- Frontend: HTML, CSS
- Backend: PHP
- Database: MySQL
- Server: WAMP

## My Role
Worked on both frontend and backend development as part of a three-member team.

## Repository
This repository contains the source code for the Travel Planning and Booking Website.
